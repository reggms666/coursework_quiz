# Функциональные требования к MVP

## Use Case: Прохождение викторины с сохранением рекордов

**Актор:** Игрок (пользователь веб-приложения)

**Предусловия:**
- Игрок открыл приложение в браузере
- В браузере доступен LocalStorage (для сохранения рекордов)

**Основной сценарий:**
1. Игрок открывает главную страницу и нажимает кнопку «Начать викторину».
2. Приложение перенаправляет на страницу `/quiz`.
3. Отображается первый вопрос с вариантами ответов.
4. Игрок выбирает один из вариантов, нажимая на кнопку.
5. Приложение проверяет ответ и подсвечивает правильный/неправильный вариант.
6. Если ответ верный, к счету игрока добавляется 10 очков.
7. Игрок нажимает «Следующий вопрос» (или приложение делает это автоматически).
8. Шаги 3–7 повторяются для всех вопросов викторины.
9. По завершении всех вопросов показывается итоговый счет.
10. Игрок вводит свое имя (или играет под именем «Вы»).
11. Результат сохраняется в таблицу рекордов и записывается в LocalStorage.
12. Игрок переходит на страницу `/records`, где видит таблицу с фильтрацией по режимам игры.

**Результат:**
Игрок завершает викторину с финальным счётом, который сохраняется в таблице рекордов. Результат доступен для просмотра в текущей сессии и после перезагрузки страницы (благодаря LocalStorage).

**Альтернативные сценарии:**
- **4a.** Игрок не уверен в ответе и нажимает «Пропустить» — вопрос пропускается, ответ остается пустым, игра переходит к следующему вопросу.
- **8a.** У игрока остались пропущенные вопросы — после прохождения остальных игра автоматически возвращает его к пропущенным.
- **11a.** LocalStorage недоступен (переполнен или отключен) — игра работает в текущей сессии, но рекорды не сохраняются после перезагрузки; выводится предупреждение.
- **12a.** В таблице нет записей, соответствующих выбранному фильтру (например, только режим «Блиц») — выводится сообщение «Нет записей».

## Границы MVP
**Входит в MVP:**
- Каркас библиотеки общих компонентов (`Button`, `Layout`).
- Настройка клиентского роутинга (`/`, `/quiz`, `/records`, `/404`).
- Верстка страниц-заглушек для Главной, Викторины и Рекордов.
- Базовая логика переключения вопросов (без сложной системы очков и сохранений).
- Адаптивная верстка для ПК.

**Не входит в MVP (будущие версии):**
- Реальная база вопросов с сервера (сейчас вопросы захардкожены).
- Авторизация и серверное хранение рекордов (сейчас только LocalStorage).
- Разные режимы игры (Классика, Блиц, Выживание) — пока только один режим.
- Таймер на ответ.
- Звуковые эффекты и сложные анимации интерфейса.
- Мобильное приложение (PWA).
