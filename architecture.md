# Архитектура курсовой работы "Викторина"

## Структура проекта
Проект реализован в виде монорепозитория и состоит из двух частей:
1. **`frontend`** — основное приложение на React. Отвечает за отображение страниц, навигацию и логику.
2. **`ui-library`** — библиотека общих компонентов.

### 1. Основное приложение (`frontend`)
**Назначение:** клиентское веб-приложение для прохождения викторины и просмотра таблицы рекордов.

## Структура папок:
```text
frontend/
├── public/
│   ├── favicon.ico
├── src/
│   ├── pages/
│   │   ├── HomePage.tsx
│   │   ├── QuizPage.tsx
│   │   ├── RecordsPage.tsx
│   │   └── NotFoundPage.tsx
│   ├── App.tsx
│   └── main.tsx
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
├── eslint.config.js
└── jest.config.ts
```

## Структура роутинга (`frontend`)
- `/` — Главная страница.
- `/quiz` — Страница викторины (содержит заглушку игры и использует `Button` из библиотеки).
- `/records` — Страница рекордов (заглушка таблицы).
- `*` — Страница 404.

### 2. Библиотека общих компонентов (`ui-library`)
**Назначение:** переиспользуемые UI-компоненты для основного приложения.

## Структура папок:
```text
ui-library/
├── src/
│   ├── Button/
│   │   ├── Button.tsx
│   │   └── Button.test.tsx
│   ├── Layout/
│   │   └── Layout.tsx
│   ├── setupTests.ts
│   └── index.ts
├── package.json
├── tsconfig.json
├── vite.config.ts
├── eslint.config.js
└── jest.config.ts
```

## Компоненты библиотеки (`ui-library`)
- **`Button`** — базовая кнопка (используется на страницах).
- **`Layout`** — компонент-обертка, содержащий навигационное меню и основной контент.

## Список используемых библиотек
- **react** (v19.3.1) — UI-библиотека.
- **react-dom** (v19.3.1) — для работы с DOM.
- **react-router-dom** (v7.18.6) — для маршрутизации.
- **vite** (v7.3.8) — сборщик проекта.
- **typescript** (v5.9.3) — типизация.
- **eslint** (v9.36.0) — линтинг.
- **jest** (v30.5.2) — тестирование.
- **@types/jest** (v30.0.0) — типы для Jest.

## Использование библиотеки компонентов
Основное приложение подключает библиотеку как локальную зависимость через npm workspaces (в package.json указано "ui-library": "file:../ui-library").

Компоненты импортируются стандартным образом:
import { Button, Layout } from 'ui-library'

Для корректной работы TypeScript и Vite в проекте настроены пути (paths в tsconfig.json и alias в vite.config.ts), которые указывают на исходный код библиотеки (../ui-library/src/index.ts).
